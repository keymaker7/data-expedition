# 아날로그 디지털 탐험대

6학년 실과 수행평가용 단일 HTML 웹앱입니다.

배포 주소: https://keymaker7.github.io/data-expedition/

GitHub Pages가 `master` 브랜치의 루트 폴더를 배포합니다. 변경 사항을 해당 브랜치에 푸시하면 자동으로 갱신됩니다.

`data-expedition.html`을 브라우저에서 열면 실행됩니다. 로컬 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 사용합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765/data-expedition.html 에 접속합니다.

학생 정보와 답안은 같은 브라우저의 로컬 저장소에 보관됩니다. 주소나 브라우저가 바뀌면 기존 답안이 이어지지 않을 수 있습니다. 공용 기기에서는 다음 학생이 사용하기 전에 ‘처음부터 다시 하기’를 누릅니다. 완료한 보고서는 인쇄/PDF 저장 또는 답 복사로 제출합니다.

별도 설치나 유료 API가 필요하지 않습니다. Google Fonts를 불러오며, 인터넷 연결이 없으면 시스템 글꼴을 사용합니다.

임시 폴더의 원본 HTML을 복사해 UI를 수정한 버전입니다. Claude 아티팩트 배포본에는 자동 반영되지 않습니다.
